# Slide visuals: technical diagrams

Produce **technical diagrams only**. Do not use raster, photos, stock images or
image-generation models. The deck is text + CSS + inline SVG.

## When a diagram is worth it

Use a diagram when the point is **spatial or structural**:

- CPU, memory, cache, bus, registers;
- paging, address translation, file layout;
- process states, protocol steps, handshakes;
- hierarchy, layers, topology, comparison of organizations.

Do **not** use a diagram when:

- the relationship is simple (3–5 items in sequence) — use `flow`, `steps` or `cards`;
- the image would only decorate the slide;
- the image would repeat the title or the body;
- there is no model in the brief. Mark `[DIAGRAMA NECESSÁRIO]` and ask; never
  invent the topology.

## Pipeline

1. **Read the raw script and the brief.** The raw script is the source; the
   brief is the contract. The diagram model lives in `## Diagramas Técnicos`.
2. **Build the visual plan.** One row per diagram: slide, priority, what it
   shows, model, labels, alt, caption.
3. **Choose the format.** CSS for simple relations; inline SVG for spatial
   structure.
4. **Generate the SVG** with `scripts/diagram-kit.mjs` (palette, type, strokes).
5. **Integrate** with `.media` (wide figure) or `.split-60-40`/`.split-40-60`
   (text + figure); add caption and alt.
6. **Validate**: `npm run validate`, `npm run audit:assets`, export PDF and
   inspect at 100%.
7. **Review**: labels legible, no overlap, palette consistent, figure inside
   the content area, no raster.

## Inline SVG, not `<img>`

An external SVG loaded through `<img>` cannot use the theme's self-hosted
fonts; labels fall back to Arial. For diagrams with text, embed the SVG in the
slide (`html: true`). External SVG is only for icon-like shapes without text.

```html
<div class="media">
  <svg viewBox="0 0 960 420" role="img" aria-label="Duas CPUs ligadas por um barramento à mesma memória">
    <!-- generated by scripts/diagram-kit.mjs -->
  </svg>
  <div class="caption">O barramento é o meio comum; a memória é o recurso compartilhado.</div>
</div>
```

The theme scales `.media svg` and `.image-card svg` automatically.

For PDF/PNG/PPTX, export with `--html`; the front matter `html: true` alone is
not enough for the image renderer. The project's `npm run export:pdf` already
passes the flag; in manual commands, include it.

In the VS Code Marp preview, set `markdown.marp.html` to `"all"`. The default
allowlist does not include inline SVG, so the preview shows the SVG as text
even though the PDF and HTML exports render it.

## Using the kit

```js
import { svg, box, arrow, bus, memory, cpu, label } from './scripts/diagram-kit.mjs';

const figure = svg({
  width: 960,
  height: 420,
  title: 'Memória compartilhada',
  desc: 'Duas CPUs conectadas por um barramento à mesma memória principal.',
  children: [
    cpu({ x: 80, y: 60, w: 180, h: 80, label: 'CPU 1' }),
    cpu({ x: 80, y: 280, w: 180, h: 80, label: 'CPU 2' }),
    bus({ x: 320, y: 190, w: 240, h: 24, label: 'Barramento' }),
    memory({ x: 620, y: 150, w: 260, h: 120, label: 'Memória principal' }),
    arrow({ x1: 260, y1: 100, x2: 320, y2: 190 }),
    arrow({ x1: 260, y1: 320, x2: 320, y2: 230 }),
    arrow({ x1: 560, y1: 202, x2: 620, y2: 202 }),
  ].join(''),
});
```

Write the generated SVG into the deck at the chosen slide. Do not keep a
duplicated asset file unless the diagram is reused across decks.

On Windows, write the SVG with Node (`fs.writeFileSync(..., 'utf8')`); do not
pass it through PowerShell pipes, which can corrupt accents.

## Style

- Palette: navy `#101f38`, ink `#1f2937`, muted `#5b6472`, line `#e3e6eb`,
  blue `#1e88e5`, purple `#7c3aed`, orange `#d9481f`, teal `#0e9f6e`.
- Titles: Oswald; labels: Roboto Mono; body: Carlito. Sizes: 20–28 px for the
  figure title, 14–16 px for labels, 12 px minimum.
- Strokes: 2 px; arrows consistent; rounded corners 4–6 px.
- No shadows, gradients or decorative borders.
- Max 7 nodes on one figure. If it needs more, split the figure.
- Figure area: `viewBox` around 960×420 for a full-width diagram; 520×320 for
  a column.

## Alt and caption

- `alt`/`aria-label` describes the **relationship**, not the pixels:
  "Duas CPUs ligadas por um barramento à mesma memória principal".
- Caption says what the student should observe, not what the shapes are.
- If the source is a brief model, add "Fonte: modelo do brief" in the caption
  only when it helps the reader.

## Review checklist

- [ ] The diagram is on the slide specified in the brief.
- [ ] It shows the relationship, not a decoration.
- [ ] Labels are legible at 100% in the PDF; no overlap or clipping.
- [ ] Palette and typography match the deck.
- [ ] `alt` and caption are present.
- [ ] SVG is inline; no raster, no remote reference, no `<image>`.
- [ ] The figure fits the content area and does not crowd the callout.
- [ ] `npm run validate` and `npm run audit:assets` pass.
